# Fusion Round 5 — Evidence-safe visual briefs

Status: FIVE BRIEFS DERIVED / HUMAN SEMANTIC REVIEW REQUIRED BEFORE ASSET PROMOTION

The repo currently proves only the pedagogical family labels ACTIVITY, PLACE, INTENTION, NEED and HABITUAL together with eight exact governed HNK runtime surfaces. It does **not** provide enough evidence in the inspected runtime artifacts to assign richer lexical glosses to every token.

Therefore the visual briefs deliberately stop at the family boundary.

## Shared art direction
- SimpleWay contextual learning image.
- One visually legible situation.
- No written HNK generated inside the artwork.
- No translation embedded in the artwork.
- No mystical/esoteric symbol may be treated as semantic evidence.
- Image is a pedagogical cue, never linguistic authority.

## Brief 01 — ACTIVITY
Authority: STR001 + exact surfaces `ERU VALI KE`, `ERU PARAZAMI KE`.
Goal: depict a clearly observable everyday activity without asserting which specific HNK token means the depicted action.
Avoid: text labels, lexical glosses, tense claims, subject/person claims.

## Brief 02 — PLACE
Authority: STR002 + exact surfaces `ERU RUMI VALIVAN KE`, `ERU RUMI PARAZAMO KE`.
Goal: depict a person/situation with an unmistakable environmental/place context while avoiding claims that any token universally means “in/at/to/from”.
Avoid: arrows implying destination/source, preposition glosses, copular explanation.

## Brief 03 — INTENTION
Authority: STR003 + exact surface `ERU DAYI KE`.
Goal: depict a context where an intended next action is visually inferable, without supplying an object/complement.
Avoid: DAYI + object, VEMI complement, future-tense explanation.

## Brief 04 — NEED
Authority: STR004 + exact surface `ERU SALI KE`.
Goal: depict a context of practical need without encoding an unauthorized object/complement in HNK.
Avoid: SALI + object, VEMI complement, universal modal explanation.

## Brief 05 — HABITUAL
Authority: STR005 + exact surfaces `SARU ERU VALI KE`, `SARU ERU PARAZAMI KE`.
Goal: depict recurrence/routine across days.
Avoid: translating SARU as “usually”; combining SARU with DAYI/SALI; claiming universal temporal word order.

## Promotion rule
These briefs authorize **asset design exploration only**. They do not promote token meanings. Each final image must be reviewed against the matching brief before the corresponding media slot can change from `REQUIRED_UNRESOLVED` to an installed/approved state.

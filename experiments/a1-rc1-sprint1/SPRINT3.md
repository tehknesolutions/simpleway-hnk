# Sprint 3 — The Grammar Dungeon

Status: **EXPERIMENTAL / HNK-A1-RC1-CANDIDATE**

World 3 adds Levels 17–24 as contrast-driven grammar traps.

## Purpose

The Dungeon teaches not only what is licensed, but also what must **not** be generalized from local RC1 evidence.

## Traps

- NE placement
- CARDINAL + COUNTABLE_OBJECT order
- VEMI as a controlled action-complement linker
- MASS_CONTENT requiring a counted container
- scoped negated location
- scoped negated existence
- predicative description vs blocked attributive NP
- scoped KE vs blocked general yes/no question

## New runtime frames

All newly materialized patch frames remain:

- HNK_AUTHORED_CANDIDATE
- LOCKED_FOR_TESTING
- generalizes: false

The Dungeon is pedagogical enforcement of RC1 boundaries, not a canon promotion.
